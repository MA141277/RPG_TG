算法一 · 三视图求交体素

目标：从 front / side / top 三视图恢复一个低精度场景体块。
逻辑：voxel(x,y,z) = front(x,y) && side(z,y) && top(x,z)。
建议先点“载入 hut1 / tower”快速验证，再上传你自己的像素图测试。

输入

建议优先使用本地文件上传，或同源 / 已开启 CORS 的图片 URL。页面会通过 fetch + blob 读取图片，避免 canvas 被污染；如果远程站点没开 CORS，浏览器安全策略仍会拦截，这种情况请先下载到本地再导入。
