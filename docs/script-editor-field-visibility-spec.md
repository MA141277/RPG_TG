# 剧本编辑器字段显隐规范 v1

## 1. 目标

剧本编辑器首先服务创作者，而不是服务运行时实现。

本规范用于约束剧本编辑器中哪些字段默认对创作者可见，哪些字段应隐藏到高级层、调试层或导出层，避免主工作台被 `ID`、`key`、`runtime family`、兼容导入标记等技术字段污染，导致界面从“创作工具”退化成“工程字段编辑器”。

## 2. 核心原则

### 2.1 创作者优先

主编辑区只展示创作者做内容决策时真正需要的信息。

### 2.2 创作语义优先于系统语义

界面字段命名必须优先使用创作语言，例如：

- `人物名称`
- `所属阵营`
- `默认所在城市`
- `人物关系`
- `事件挂载`

不得把以下系统术语作为主界面核心文案：

- `entity id`
- `record key`
- `runtime family`
- `compatibility import`

### 2.3 系统字段默认隐藏

运行时、导出、兼容、索引层字段默认不进入主工作台首屏，也不应在对象列表、对象头部、基础表单中显性占位。

### 2.4 必要时进入高级层

确有查看需要的系统字段，只能进入以下区域之一：

- `高级设置`
- `开发信息`
- `导出调试信息`

这些区域应默认折叠，不抢主流程焦点。

## 3. 字段分层模型

### 3.1 A 层：创作者可见字段

定义：会直接影响人物塑造、剧情组织、世界设定、对象关系、导出判断的字段。

#### 人物页

- 人物名称
- 身份 / 分类
- 所属阵营
- 默认所在城市
- 人物简介
- 核心属性
- 扩展属性
- 人物关系
- 势力归属
- 建筑归属
- 事件挂载

#### 城市页

- 城市名称
- 城市定位
- 所属区域
- 城市简介
- 关联人物
- 关联建筑
- 可触发事件
- 城市属性

#### 建筑页

- 建筑名称
- 建筑类型
- 所属城市
- 建筑简介
- 可进入角色
- 可触发事件
- 功能属性

### 3.2 B 层：系统隐藏字段

定义：主要服务内部映射、运行时执行、兼容导入、导出封装、调试追踪的字段。

典型包括：

- 对象 ID
- 内部 key
- runtime family
- compatibility import 标记
- unresolved family 信息
- manifest 引用字段
- 内部排序号
- 系统保留标识
- 导出专用字段
- 调试辅助字段

## 4. 页面级显示规则

### 4.1 顶部工具栏

顶部只允许出现全局动作：

- 返回剧本列表
- 保存
- 校验
- 导出

顶部不得放置：

- 对象 ID
- runtime 标记
- compatibility family 信息
- 内部技术状态原文

### 4.2 左侧一级导航

左侧一级导航只表达创作对象分类：

- 人物
- 城市
- 建筑

不得在一级导航中展示任何系统字段。

### 4.3 左侧二级对象列表

对象列表只显示创作者识别对象所需信息：

- 对象名称
- 对象分类摘要
- 简要状态

对象列表默认不显示：

- 内部 ID
- key
- runtime family
- 内部索引号

### 4.4 中央主编辑区

中央主编辑区只承载当前对象的创作表单与创作关系配置。

对人物页而言，基础信息区默认允许出现：

- 人物名称
- 身份 / 分类
- 所属阵营
- 默认所在城市
- 人物简介

默认不允许出现：

- 人物 ID
- 内部 key
- runtime family

### 4.5 校验与导出区

校验信息应优先使用创作语义表达问题，例如：

- “人物缺少默认所在城市”
- “该建筑尚未绑定所属城市”
- “事件挂载缺少目标对象”

不应默认直接向创作者暴露内部字段名。

若技术字段必须出现，只能通过“展开技术详情”显示。

## 5. 交互规则

### 5.1 新建对象

- 新建对象时，系统字段自动生成。
- 创作者只填写创作语义字段。
- 不要求创作者手填 ID 或 key。

### 5.2 切换对象

- 对象切换以对象名称为主。
- 列表和标题区不以 ID 作为主要识别方式。

### 5.3 删除对象

- 删除确认文案必须使用对象名称。
- 不得以纯技术标识作为删除确认主体。

### 5.4 复制对象

- 创作者面向“复制人物”“复制城市”“复制建筑”。
- 系统内部 ID / key 的复制与重建逻辑由系统自行处理。

## 6. 例外场景

以下场景允许显示系统字段，但必须进入次级层：

- 开发调试模式
- 导入兼容修复模式
- 导出诊断模式
- 高级设置被主动展开

即便显示，也应遵循以下要求：

- 使用 `系统信息`、`开发信息`、`技术详情` 等标题。
- 放入折叠块、抽屉或诊断面板。
- 不进入主创作流首屏。

## 7. 当前人物编辑页落地结论

基于当前已确认的人物编辑态，人物页应做如下约束：

- 去掉 `人物 ID` 主区展示。
- 去掉对象头部中的技术标识显示。
- 保留名称、分类、阵营、城市、简介、属性、关系、事件。
- 如确需查看内部标识，只允许进入 `高级设置`。

## 8. 设计验收标准

满足以下条件时，视为字段显隐符合规范：

- 创作者不需要理解内部实现字段即可完成编辑。
- 主工作台首屏看不到 `ID`、`key`、`runtime` 等技术术语。
- 校验提示以创作语义为主，而不是内部字段原文。
- 系统字段即使存在，也被限制在高级层或调试层。
- 编辑器整体观感更像“创作工作台”，而不是“底层数据表单”。
