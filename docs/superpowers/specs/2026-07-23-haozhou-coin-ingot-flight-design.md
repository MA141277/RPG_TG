# 濠州地图银两获得飞元宝动画设计

## 目标

为游戏增加一套可复用的“获得银两”表现层，并先在濠州城市地图上提供一个测试按钮。点击后立即给玩家增加 `10 文`，同时播放从按钮中心喷发元宝并飞向左上角银两 HUD 的动画。

## 范围

本次只覆盖两部分：

1. 全局银两获得动画控制器
2. 濠州城市地图测试按钮

暂不把该动画接入其他真实奖励流程，但实现必须可复用，后续其他“加银两”入口可以直接调用。

## 用户体验

点击濠州测试按钮后，动画按以下四段执行：

1. 爆发：从按钮中心喷出 `10~20` 个元宝图标，向按钮周围随机散射。
2. 减速停顿：元宝迅速减速，并在空中停顿约 `0.5s`。
3. 飞行归拢：全部元宝沿随机贝塞尔曲线飞向左上角银两 ICON。
4. 数值滚动：第一个元宝命中目标时开始滚动银两数值，最后一个元宝命中时定格为最终值。

真实银两数值在点击时就写入游戏状态；动画只负责表现，不决定最终资源结算。

## 架构

### 1. 全局奖励动画器

新增一个全局 UI 动画层，挂在主 UI 根节点内但高于普通页面内容。该层负责：

- 管理元宝实例对象池
- 计算起点与终点屏幕坐标
- 驱动喷发、停顿、归拢的帧动画
- 临时覆盖 HUD 银两数字的显示值

该动画器不直接依赖濠州地图，仅暴露一个通用入口，例如：

- 输入：起点元素或点击坐标、奖励金额、目标 HUD 元素
- 输出：一次完整的表现播放

### 2. HUD 目标定位

左上角银两目标点不写死。运行时从全局玩家面板中读取银两图标或银两文本容器的 `getBoundingClientRect()`，取其视觉中心作为归拢终点。

这样即使后续 HUD 调整布局或缩放，动画仍能自动对齐。

### 3. 金额显示策略

点击按钮后：

- 先更新真实游戏状态，玩家银两立即 `+10`
- 动画器记录“表现起始值”和“表现目标值”
- HUD 在动画期间显示一个临时滚动值
- 动画结束后回到正常渲染，重新以真实状态为准

这样可以避免：

- 动画失败导致真实资源未更新
- 多次叠加时只靠动画值计算而产生漂移

## 动画细节

### 元宝数量

- 每次生成 `10~20` 个元宝
- 数量可按奖励金额做轻度缩放，但濠州测试按钮固定调用时无需额外分段

### 爆发阶段

- 起点为按钮中心；如果存在点击事件坐标，则优先使用点击坐标
- 初速度方向随机，角度覆盖按钮周围一圈
- 距离和速度做轻微随机抖动，避免机械一致

### 停顿阶段

- 元宝在散射末端停顿约 `0.5s`
- 各元宝进入归拢的起始时刻允许有少量随机偏移，形成“逐个回收”的感觉

### 归拢阶段

- 每个元宝生成一条二次贝塞尔曲线
- 控制点位于散射终点与银两 HUD 终点之间，并加入随机上抛或侧偏
- 命中顺序不必绝对同步，但最后一个元宝必须可靠触发“定格最终值”

### 数值滚动

- 第一个命中目标的元宝触发数字滚动开始
- 滚动值以时间插值推进，不要求一文一文逐帧加
- 最后一个元宝命中时强制写成目标值，结束临时显示态

## 资源与样式

- 元宝图标优先复用项目现有银两/金币相关 UI 资产
- 若当前没有合适的单个元宝图标，可先从现有金钱类资源中选一个视觉最接近的素材
- 动画层样式需保证：
  - 不阻断正常 HUD 显示
  - 元宝可超出页面局部容器裁切
  - 高于地图内容，低于必要的全屏模态层

## 濠州测试按钮

在濠州城市地图加入一个普通可见按钮，作为临时测试入口。

要求：

- 永久显示，直到后续手动删除
- 点击后执行 `+10 文`
- 同时调用全局银两获得动画
- 文案清晰，能直接看出是测试用途

该按钮仅用于验证功能，不参与正式玩法设计。

## 错误处理

若动画器在运行时找不到银两 HUD 目标元素：

- 仍然完成真实加钱
- 动画退化为仅播放按钮周围的喷发效果，或直接跳过表现
- 不允许因为表现失败阻断资源更新

若连续快速点击测试按钮：

- 每次点击都应成功加钱
- 动画可并行排队或并行播放
- HUD 临时滚动值以最近一次目标值为收束点，避免最终显示落后于真实状态

## 测试策略

先补自动化测试，再实现功能。

### 自动化测试

1. 濠州地图视图测试
   - 按钮存在
   - 按钮带有稳定的 `data-action`

2. 主运行时测试
   - 点击该按钮会增加玩家 `10 文`
   - 会触发全局银两奖励动画入口

3. 动画控制器测试
   - 首个元宝命中后开始数字滚动
   - 末个元宝命中后定格到最终值
   - 找不到目标元素时不影响真实加钱

### 手动验证

在濠州地图中点击测试按钮，确认：

- 元宝从按钮中心喷发
- 有明显停顿
- 元宝飞向左上角银两区域
- 数字从旧值滚动到新值
- 最终值与真实资源一致

## 非目标

本次不做以下内容：

- 不接入全部房屋/事件/结算奖励入口
- 不新增复杂音效
- 不引入第三方动画库
- 不修改真实资源系统的结算规则
