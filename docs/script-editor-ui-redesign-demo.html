项目入口重设计

把“选择项目”和“编辑项目”拆开

列表页只负责新建、导入、继续编辑、删除。进入项目后，工作台只做当前项目创作。

3 个项目 2 个可导出 1 个有阻塞

为什么更合理

职责更清楚 项目选择和项目编辑不再混在一个页面里。
首屏更聚焦 工作台首屏直接进入对象导航和具体配置。
删除更安全 项目删除通过统一确认流程处理。
像真正编辑器 左侧选对象，中间改配置，右侧看摘要。
