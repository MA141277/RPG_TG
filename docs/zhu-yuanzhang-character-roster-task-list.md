# 朱元璋立志传时期历史人物表任务列表

目标：建立一套可持续维护的“朱元璋早年立志传”人物表。范围尽量详尽，按势力整理，从核心人物到史书中仅有零散记载的人物都保留候选位。实际进入游戏时再按章节、城市、剧情权重筛选。

## 1. 时间与叙事范围

- 主时间段：约 1344-1356 年。
- 起点：朱元璋家破、入皇觉寺为僧、游方乞食。
- 核心阶段：濠州投郭子兴、红巾军内斗、独立发展、南下江淮、攻取集庆路。
- 阶段终点：朱元璋占集庆，改名应天前后。
- 主地图基点：濠州/钟离。
- 注意：当前模组开局偏 1362 年，许多人物已处于后期状态。项目的人物表要允许“史实早年状态”和“模组后期状态”并存。

## 2. 优先级定义

- `P0 必做`：立志传主线必须出现，缺失会影响剧情成立。
- `P1 重要`：重要势力、核心事件、主要城市需要出现。
- `P2 候选`：史书有名，适合支线、城市场景、传闻、事件背景。
- `P3 背景`：有记录但信息少，可作为文本、传闻、一次性事件或阵营补位。
- `待考`：名字或归属需要进一步核实，不能直接写死为史实。

  displayName: string;

  birthYear: number | null;
